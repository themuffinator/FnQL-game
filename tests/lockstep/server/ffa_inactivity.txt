# g_inactivity 4 --set g_inactivityWarning 2 [--set g_dropInactive 0]):
# the retail inactivity timer (qagamex86 0x10033fd0).  Alpha idles from the
# start and gets the warning after two seconds, then the drop (or, with

# after its warning: speaking restarts the count, not the warning flag, so
# it gets no second warning before its later drop.  Dave stays a spectator,
# which never counts.
