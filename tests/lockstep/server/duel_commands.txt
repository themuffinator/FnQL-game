# Gate G3 scenario (scripts/server_lockstep.py --factory duel --frames 1300
# --scenario ...): a duel on campgrounds with auto actions and the stats
# commands.  Alpha asks for demos and screenshots (cg_autoAction 3), bravo
# for demos (1) and charlie, who waits in the queue, for screenshots (2).
# Alpha and bravo ready up; the countdown starts the demos, the restart
# into the match and a suicide follow, and alpha leaves mid-match so the
# duel is forfeited; four seconds into the intermission the demos stop and
# the screenshots are taken, each with retail's file name.  Along the way
# acc and pstats are asked for during the warmup, the match and the
# intermission, by players and by a follower, and charlie rage quits.
# Frames are server frames: 25 msec each at the default sv_fps 40.
# Grammar: FnQL docs/fnql/SERVER_LOCKSTEP.md.

clientcmd 24 bravo readyup
